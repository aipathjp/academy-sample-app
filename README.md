# 議事録と ToDo（第1章のスタート地点）

I-Path Academy 新カリキュラムの見本アプリの、**第1章を始める地点**です。名前と「ようこそ」の画面だけがあります。
完成版は `main` の枝にあります。

## 自分の PC で動かす手順

```bash
git clone --branch ch1-start https://github.com/aipathjp/academy-sample-app.git
cd academy-sample-app
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開くと、「ようこそ！」の画面が出ます。
